# 🏦 Banco Internacional de Hyrule ⚜️
## Programa desarrollado en Python que permite gestionar un sistema bancario mediante la creación y administración de sucursales.
<img src="src/img/imgBanco.png" width="300">

### 👾 Tecnologías usadas

- *Lenguaje: **Python***
- *Librerías: **Tkinter, Pillow y JSON***

### 📍 Características Principales

- Interfaz gráfica: Utiliza la librería **tkinter** para crear las ventanas, botones, etiquetas y formularios de la aplicación.
- Creación del banco: Permite registrar y configurar la información principal del Banco Internacional de Hyrule.
- Administración de sucursales: Permite gestionar las sucursales pertenecientes al banco.
- Clases: El proyecto utiliza programación orientada a objetos para organizar las diferentes partes del sistema.
- Archivos JSON: Se utilizan para almacenar y manejar información del sistema.
- Imágenes: Utiliza recursos gráficos para complementar la interfaz de la aplicación.
- Ventanas y menús: Cuenta con diferentes interfaces para navegar entre las funciones del programa.
- Validaciones: El programa realiza validaciones de los datos ingresados para evitar registros incorrectos o repetidos.

### Instalación

**Para ejecutar el proyecto✅:**
1. Descarga o clona este repositorio.
***git clone https://github.com/Halinxx14/Banco-Internacional-de-Hyrule.git***
2. Ingresa a la carpeta del proyecto: ***cd Banco-Internacional-de-Hyrule***
3. Asegúrate de tener instalado Python.
4. Ejecuta el archivo principal:  ***python main.py***

### Uso

**Al iniciar el programa se muestra la interfaz principal del Banco Internacional de Hyrule.**
**Desde el sistema se pueden realizar diferentes acciones relacionadas con la administración del banco y sus sucursales.**

El programa permite:

- Crear y configurar el banco.
- Registrar información de las sucursales.
- Administrar las sucursales existentes.
- Consultar y modificar información.
- Guardar información utilizando archivos JSON.
